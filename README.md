# Alexandre Vives — Portfolio

Personal data science portfolio. Built with Next.js 15, Tailwind CSS, Framer Motion and Recharts.

## Dev

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Stack
- Next.js 15 (App Router, RSC)
- TypeScript
- Tailwind CSS (custom dark theme, lime accent)
- Framer Motion (scroll animations)
- Recharts (case-study visualizations)
- Deployed on Vercel

## Add your photo
Drop a `me.jpg` (square, ~600×600) into `public/` and the hero will use it.
The PDF resume lives at `public/Alexandre_Vives_resume.pdf`.

## Editing content
Project case studies and copy live in `src/content/projects.ts` and the page components under `src/components/sections`.
